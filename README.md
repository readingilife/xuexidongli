# 基础英语 850 单词学习工具

一个简单实用的基础英语 850 单词学习网页工具，帮助你快速学习和掌握基础英语词汇。

## 功能特点

- 📚 **完整单词库**：包含 C.K. Ogden 基础英语 850 个核心单词
- 🔊 **发音功能**：点击单词即可使用标准美式发音
- 📖 **音标显示**：每个单词都配有国际音标
- 🇨🇳 **中文翻译**：提供详细的中文释义
- 💫 **交互体验**：
  - 点击单词立即发音并显示详情
  - 悬停 800ms 自动显示单词信息卡片
  - 卡片智能定位，不会超出视窗范围
- 🖨️ **打印版本**：提供专门优化的打印页面

## 单词分类

单词分为四大类：

1. **Operations (100 个)** - 动词、介词、代词等功能词
2. **Things - General (400 个)** - 抽象和一般事物名词
3. **Things - Picturable (200 个)** - 具体可想象的事物名词
4. **Qualities (150 个)** - 形容词和描述性词汇

## 使用方法

### 在线使用

直接用浏览器打开 `basic_english_850.html` 文件即可使用。

### 本地使用

1. 克隆或下载本项目
2. 用浏览器打开 `basic_english_850.html`
3. 开始学习！

### 打印学习

打开 `basic_english_850_print.html` 文件，使用浏览器的打印功能打印出来。

## 技术实现

- **纯 HTML/JavaScript**：无需任何框架，直接运行
- **Web Speech API**：利用浏览器原生语音合成功能
- **响应式设计**：适配不同屏幕尺寸
- **无依赖**：零依赖，开箱即用

## 关于基础英语 850 单词

基础英语 (Basic English) 是由英国语言学家 C.K. Ogden 于 1930 年代创造的一套简化英语，包含 850 个核心单词，据研究可以表达 90% 以上的日常交流需求。这套词汇系统适合英语初学者，也适合作为第二语言的入门学习材料。
