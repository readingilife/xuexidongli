# 学习力报告编辑器 - 使用说明

## 快速开始

### 1. 打开编辑器
直接双击打开 `CMS/report-editor.html`，或在浏览器中打开该文件

### 2. 编辑报告
- 左侧面板用于编辑学生信息和报告内容
- 修改内容时，右侧会自动更新预览
- 支持添加/删除各项要点

### 3. 下载报告
点击「📥 下载报告」按钮，HTML文件会自动下载

### 4. 放置文件
将下载的文件复制到 `xuexili` 目录中

## 文件名规则
- 格式: `姓名全拼 + 年级数字.html`
- 示例: `liupinyan7.html` (刘品延 - 7年级)

## 添加更多学生姓名拼音映射

如需支持更多学生姓名，请编辑 `report-editor.html` 中的 `pinyinMap` 对象:

```javascript
const pinyinMap = {
    '刘':'liu','品':'pin','延':'yan',
    '张':'zhang','三':'san',
    '李':'li','四':'si'
};
```
